### Query 7: Groupby Aggregation (Complex / LLM code-gen)
**Question:** What is the total revenue per region?

```markdown
### 📊 Answer
The region generating the highest revenue is **North** with **$6,769.77**, followed by East ($2,347.78), South ($2,627.88), and West ($2,657.85).

### 🐍 Code
```python

| East | $2,347.78 |

### 📝 Methodology & Assumptions

- Values sorted descending by revenue.
```

## Anti-Hallucination Methodology Notes

1. **Deterministic Execution:** Every figure is generated by executing real Python pandas code against the raw DataFrame in a local isolated execution environment (`dataiq/executor.py`).
2. **Context Minimization:** Only `df.head(5)` and `dtypes` are sent to the LLM. The full dataset is **never** sent in prompt text, eliminating context-window truncation or hallucinated numbers.
3. **Reproducibility Guarantee:** Every response includes the exact pandas code snippet that produces the result, allowing users to run the same code in Jupyter or Python to independently verify numbers down to the cent.
